# Arcanum

Remake fidèle de **Tales of Magic** (RedMoon Studios, 2007–2010) : un jeu de rôle multijoueur par navigateur (PBBG), en mode texte et menus, où l'on incarne un(e) apprenti(e) sorcier(ère) qui intègre une école de magie et progresse pour devenir le meilleur mage du monde.

- **Documentation complète** : [`docs/`](docs/README.md) — vision, game design, spec technique, direction artistique, roadmaps.
- **Stack** (actée) : Django 5.2 LTS · PostgreSQL 16 · HTMX — voir [`docs/adr/ADR-001-stack.md`](docs/adr/ADR-001-stack.md).
- **Workflow** : issue → branche auto → PR → squash sur `main` — voir [`CONTRIBUTING.md`](CONTRIBUTING.md).

> Identité 100 % originale : aucun asset, texte ou marque du jeu original (propriété CRATR.games GmbH) n'est utilisé — voir `docs/08_REFERENCES_ORIGINAL.md`.
